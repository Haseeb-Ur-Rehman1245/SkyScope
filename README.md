# 🌤️ SkyScope – Live Weather Intelligence Dashboard

A modern, visually stunning weather dashboard that provides real-time weather insights with a clean glassmorphism UI and dynamic interactions.


## 🚀 Features

✨ Real-time weather data (OpenWeather API)  
🌡️ Current temperature, humidity & wind  
📊 5-day forecast & hourly updates  
🤖 AI-powered weather insights  
🌙 Day / Night mode toggle  
🎨 Glassmorphism UI design  
⚡ Smooth animations & transitions  
🌍 Responsive layout (mobile + desktop)  
🌟 Particle background effects  


## 🎯 Weather Highlights

- 🌡 Feels Like Temperature  
- 🌅 Sunrise & Sunset Time  
- 🌍 Visibility  
- 📡 Live data updates  


## 🛠️ Tech Stack

- HTML5  
- CSS3 (Glass UI + Animations)  
- Vanilla JavaScript  
- OpenWeather API
